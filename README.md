# Codex Manager Releases

Публичный binary-only канал обновлений Codex Manager для macOS.

Здесь публикуются только:

- `release-feed.json` для встроенной проверки обновлений;
- готовый Universal 2 DMG;
- SHA-256 контрольная сумма образа.

Исходный код хранится отдельно в приватном репозитории. Пользовательские
настройки, OpenAI-аккаунты, auth vault и ключи провайдеров сюда не входят.

Codex Manager — независимый проект и не является продуктом OpenAI.

Текущая стабильная версия — **0.9.2**:
[скачать приложение](https://github.com/zaurocrvjob/codex-manager-releases/releases/tag/v0.9.2).
В версии 0.8.7 откройте настройки обновлений и проверьте новую версию.
Пользователям 0.8.5 с ошибкой TLS потребуется одна ручная установка 0.9.2;
встроенный набор доверенных сертификатов сохраняется в новом релизе.

0.9.2 добавляет «Открыть обновление…» в Settings и повторно открывает окно
после ручной проверки. Если в 0.9.0/0.9.1 приглашение уже закрыто и больше
не открывается, скачайте 0.9.2 вручную: замените только приложение Manager,
не удаляйте настройки и авторизации. Сам Codex закрывать не требуется.
Закрытие окна обновления больше не лишает доступа к установке.

0.9.1 исправляет счётчики задач и субагентов, оформление и комплект legacy-
обновления. Добавление аккаунта доступно в Sources; настоящий вход через Chrome
проверен в отдельном тестовом хранилище без переключения рабочего аккаунта.
В строке меню — короткий номер аккаунта, число исполнителей и ограничивающий
лимит; понятные названия и модели доступны внутри панели. Подпись приложения
ad-hoc; Apple Developer ID и notarization пока отсутствуют.
