# Codex Manager Releases

Публичный binary-only канал обновлений Codex Manager для macOS.

Здесь публикуются только:

- `release-feed.json` для встроенной проверки обновлений;
- готовый Universal 2 DMG;
- SHA-256 контрольная сумма образа.

Исходный код хранится отдельно в приватном репозитории. Пользовательские
настройки, OpenAI-аккаунты, auth vault и ключи провайдеров сюда не входят.

Codex Manager — независимый проект и не является продуктом OpenAI.
